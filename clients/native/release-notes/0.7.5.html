Unpeel 0.7.5

  • Archive is gone; Stop keeps a resumable row. Stopping a session leaves it in the sidebar's stopped list with Resume and drops its old scrollback. Archived sessions kept their terminal output forever (about a gigabyte on a daily-driver Mac) and slowed every rescan; the ones you have become stopped rows on update. Stopped sessions beyond Stopped sessions to keep (5 per group by default) are removed; pinned and unread ones stay, and the agent's own history still holds the conversation.
  • Settings ▸ Git. Sign in to GitHub with a device code and set your Git name and email for the selected workspace's Host, including a remote Mac. Credentials stay in that Host's account and never travel to the app.
  • Agents report their own status. Programs that speak the Program Status Protocol (OSC 7501), including Claude Code 2.1, now tell Unpeel directly when they are working, done, blocked, or failed. That is more precise than hooks, which remain the fallback for other agents.
  • Agent access per session. Right-click an agent session ▸ Agent access: Read (the default), Write (types into other sessions without asking), or Create & remove (can also start sessions and close the ones it started). A change reaches a running agent without a restart.
  • New sessions in other workspaces show up at once, selected and marked as starting, instead of appearing a moment later unselected.
  • ⌘K works while another Host is selected.
  • Fit to phone works in every workspace. It was ignored for sessions outside your main workspace.

Also in 0.7.4

  • ⌘K opens in every workspace. The command palette was reachable only in your main workspace. It now opens in every scope and leads with what is spinning or done across all of your workspaces — the same activity the Recent-activity dropdown shows — and jumping to one of those rows switches to its workspace.
  • Sessions stuck after a full disk can be removed. When the disk filled up, a session could stay running forever with a dead child and no control socket, and "Couldn't remove the session". Such a session now ends cleanly, its exited state lands once space returns, and Remove works. A session whose host stopped answering can also be stopped and removed even when its child can't be verified.
  • Group renames stick. Renaming a sidebar group through the Host survives relaunch instead of reverting.
  • See why a paired Mac is out of reach. When a paired Mac is on another network, the reason now says to use Unpeel Link or set up Tailscale, rather than failing silently.
  • Pairing on iPad. The pairing sheet now presents correctly on iPad.
